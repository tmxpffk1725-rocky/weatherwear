# WeatherWear 산출물 (docs)

날씨 기반 의류 코디 추천 웹앱 **WeatherWear**의 프로젝트 산출물 모음.
ManageGear 산출물 세트의 구조를 본떠, **스카이 블루 테마**로 작성했다.

## 구성

| 파일 | 내용 |
|------|------|
| `00_기획서.xlsx` | 배경·가설·문제→해결·핵심기능·디자인·추천로직·기술스택·로드맵 |
| `01_요구사항정의서.xlsx` | 사용자 관점 요구사항(REQ) + 우선순위·구현상태 |
| `02_기능정의서.xlsx` | 시스템 관점 기능(F) + 동작정의, API 목록 |
| `03_DB설계서.xlsx` | 테이블·관계·저장방식·설계결정 |
| `04_품질보안점검.xlsx` | 상용 기준 품질·보안 점검표(P0~P2) + 현재 강점 |
| `정책결정관리서.xlsx` | 핵심 의사결정 기록(DEC) |
| `DDL.sql` | DB 스키마(SQLite, backend/db.js 정본) |
| `seed.sql` | 예시 데이터(문서용, 운영 DB 비대상) |

각 엑셀에는 **변경이력** 시트가 있어 버전별 갱신을 기록한다.

## 한눈에 보는 WeatherWear

- **제품**: 오늘 날씨(체감·일교차·강수)에 맞는 코디 3세트를 AI가 설계하고 네이버 쇼핑 구매로 연결. 옷장(보유 옷) 반영 — 사진 AI 등록(비전) 포함, 찜, 계정별 동기화.
- **프론트**: React 19 + Vite, 모노크롬 CSS, 모바일 웹 → Vercel
- **백엔드**: Node 20 + Express + SQLite → 오라클 클라우드 VM(systemd + Caddy HTTPS)
- **추천**: Vercel 함수 `/api/outfit`(Claude Haiku) + `/api/shop`(네이버 프록시) + `/api/vision`(옷 사진 분석)
- **날씨**: 기상청 단기예보(백엔드 프록시 + 격자 캐시), GPS + Nominatim, 24절기
- **인증**: 이메일/비밀번호(JWT+bcrypt) + 이메일 인증(Gmail SMTP)

## 갱신 규칙

기능·정책·DB가 바뀌면 해당 산출물의 본문을 고치고 **변경이력 시트에 새 버전 행을 추가**한다(이전 이력 보존). 메타행의 `버전`·`작성일`도 함께 갱신한다.
